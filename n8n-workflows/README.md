# n8n 워크플로우 설정 가이드

## 📋 준비사항

### 1. n8n Data Table에 새 식당 추가

n8n Data Table (`센텀밥집데이터`)에 다음 레코드를 추가하세요:

| restaurant_id | current_title |
|--------------|--------------|
| 2            | (빈 값)       |
| 5            | (빈 값)       |

- **restaurant_id 2**: 큐비e센텀(다와)
- **restaurant_id 5**: 에이스하이테크(다와)

### 2. 백엔드 재시작

```bash
cd backend
npm start
```

새로운 API 엔드포인트가 활성화됩니다:
- `POST /api/webhook/upload-json-data`

## ⚠️ 중요: 워크플로우 수정 필요

임포트 후 **"제목 비교" 노드**를 다음과 같이 수정하세요:

### 현재 (잘못됨)
```json
{
  "name": "current_title",
  "value": "={{ $json.current_title }}"
},
{
  "name": "prev_title",
  "value": "={{ $json.current_title }}"  // ❌ 잘못됨!
}
```

### 수정 후 (올바름)
```json
{
  "name": "new_title",
  "value": "={{ $('게시글 제목 추출').item.json.current_title }}"
},
{
  "name": "prev_title",
  "value": "={{ $('이전 제목 조회 (큐비)').item.json.current_title }}"  // 또는 '이전 제목 조회 (에이스)'
}
```

### "If (새 게시글이면)" 노드도 수정
```json
{
  "leftValue": "={{ $json.new_title }}",
  "rightValue": "={{ $json.prev_title }}"
}
```

## 📅 스케줄 설정

기본 스케줄: **매주 월요일 10-11시, 30분마다** (총 3회 실행)
- `0 0/30 10-11 * * 1`

원하는 시간으로 변경 가능:
- 매주 월요일 10시: `0 0 10 * * 1`
- 매일 오전 11시: `0 0 11 * * *`

## 🔄 작동 방식

```
[스케줄 트리거]
  ↓
[이전 제목 조회] + [블로그 크롤링]
  ↓
[HTML 파싱 → 게시글 제목 추출]
  ↓
[Merge: 새 제목 + 이전 제목]
  ↓
[If: 제목이 다르면?]
  ↓ (Yes)
[메뉴 데이터 파싱]
  ↓
[백엔드 업로드]
  ↓
[Data Table 제목 업데이트]
  ↓
[텔레그램 알림]
```

## 🎯 중복 업로드 방지

- 게시글 제목을 n8n Data Table에 저장
- 스케줄러가 돌 때마다 새 게시글인지 확인
- 같은 게시글이면 업로드 스킵
- 새 게시글이면 업로드 후 제목 업데이트

## 📝 테스트

1. n8n에서 워크플로우 수동 실행
2. 백엔드 로그 확인:

   ```
   [웹훅 JSON 업로드] 성공: 다와푸드 - 1.26-1.30
   ```

## 🐛 트러블슈팅

### 업로드가 안 됨
- Data Table에 해당 restaurant_id 레코드가 있는지 확인
- 백엔드 로그 확인
- 활성 날짜 범위가 설정되어 있는지 확인

### 매번 중복 업로드됨
- "제목 비교" 노드가 올바르게 수정되었는지 확인
- Data Table의 `current_title`이 업데이트되는지 확인

### 메뉴 데이터가 비어있음
- 네이버 블로그 URL이 올바른지 확인
- HTML 파싱 로직 확인 (테이블 구조 변경 가능성)
